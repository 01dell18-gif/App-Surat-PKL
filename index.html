Pengaturan Aplikasi & Lembaga

Kop Surat, TTD Elektronik & Basah, Logo Web, Sekolah, TA & Database

1. Gambar Kop Surat

Standar Bawaan (kop.png)

Format file: PNG, JPG, JPEG, WEBP. Dapat diunggah langsung atau melalui link URL.

Disimpan secara lokal di browser dan backend database.

Masukkan URL langsung berkas gambar kop resmi.

2. Tanda Tangan Elektronik / Barcode Kepala Sekolah

Standar Bawaan (ttdelektronik.jpg)

Digunakan saat opsi "Gunakan TTD Elektronik" dicentang.

Disimpan secara lokal di browser dan backend database.

Masukkan URL langsung berkas gambar TTD/barcode.

3. Tanda Tangan Basah Kepala Sekolah

Standar Bawaan (ttd_basah.png)

Digunakan otomatis jika TTD Elektronik tidak digunakan, disertai Nama & NIP resmi Kepala Sekolah.

Format PNG transparan sangat disarankan untuk hasil cetak yang bersih.

Masukkan URL langsung ke berkas gambar TTD basah.

4. Logo Web Aplikasi & Favicon

Standar Bawaan (logo_fyj.png)

Ditampilkan pada pojok kiri atas bilah navigasi header dan tab peramban.

Pratinjau Ikon Aplikasi
Rekomendasi rasio 1:1 (persegi), format PNG transparan atau JPG

Disimpan secara lokal di browser dan langsung diterapkan.

Masukkan URL langsung ke berkas logo.
